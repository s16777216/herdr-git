# Herdr Git Keyboard Shortcuts

| Shortcut | Context | Action |
|---|---|---|
| `⌘⏎` / `Ctrl+Enter` | Commit Box | Commit staged changes (or all changes if none staged) |
| `j` / `k` / `↑` / `↓` | Changes List | Move focus between file rows and section headers |
| `s` | Changes Row | Stage file / hunk |
| `u` | Staged Row | Unstage file / hunk |
| `d` | Changes Row | Discard changes (prompts confirmation) |
| `m` | Any | Open Git contextual action menu |
| `Tab` | Panel | Switch focus between Changes list and Commit Graph |
